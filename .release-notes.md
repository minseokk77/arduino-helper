## v0.7.7

### Development tooling

- Switched the repository from npm lockfiles to `pnpm`.
- Added `packageManager: pnpm@10.18.3`.
- Added `@vscode/vsce` as a dev dependency so packaging works through `pnpm run package`.
- Excluded `pnpm-lock.yaml` from the VSIX package.

- Rewrote README in clean English and removed mojibake.
- Rewrote release notes to remove mojibake.
- Repaired Korean package metadata.

- Corrected the repository URL to `minseokk77/arduino-helper`.

## v0.7.6

### Serial communication

- Added a new `Arduino: Serial Console` webview.
- Added TX/RX log display, baud rate selection, line ending selection, pause, autoscroll, clear, export, and input history.
- Added `arduino.serialLineEnding` with `none`, `lf`, `cr`, and `crlf` options.
- Reused the existing `arduino-cli monitor` process so the terminal monitor, plotter, and console share the same serial stream.

### Board and port selection

- Added the missing `Arduino: Select Port` command.
- Added `Arduino: Select Board and Port`.
- Fixed flows where the upload or serial monitor dialog showed `Select Port` but did not open a port picker.
- Allowed selecting detected ports even when `arduino-cli` cannot match them to a known board. This improves Linux and VSCodium compatibility.

### Packaging and metadata

- Excluded local `.env*` files from VSIX packages.
- Updated `package-lock.json` version metadata to match `package.json`.
- Rewrote `.gitignore` as a clean UTF-8/ASCII file.
- Refreshed README and release notes to remove mojibake.

## v0.6.0

- Added memory usage display after compile.
- Added dependency management through `arduino.json`.
- Added serial timestamp, hex view, and serial log export options.
